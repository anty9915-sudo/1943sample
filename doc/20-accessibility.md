# Accessibility 구현 문서

## 기본

모든 사용자가 사용할 수 있도록 접근성을 고려한다.

## Image

모든 의미 있는 이미지에는 alt를 작성한다.

## Button

Button에는 명확한 목적을 표시한다.

## Navigation

키보드 Tab으로 모든 메뉴에 접근할 수 있어야 한다.

## Focus

Focus 상태를 제거하지 않는다.

필요하면 Gold Outline을 사용한다.

## Color

Black + Gold 조합에서도 텍스트가 읽기 쉽게 충분한 대비를 확보한다.

## Mobile

터치 영역은 충분히 크게 만든다.

## Reduced Motion

사용자가 운영체제에서 Motion 감소를 설정한 경우 Animation을 최소화한다.

## 목표

디자인뿐만 아니라 실제 사용할 수 있는 웹사이트를 만든다.
