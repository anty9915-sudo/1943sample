# Loading Screen 구현 문서

## 목표

사이트 첫 진입 시 브랜드를 보여주는 Loading Screen.

## Design

전체 화면:

```text
BLACK
```

중앙:

```text
1943

CLASSIC
```

하단:

```text
LOADING...
```

## Animation

Logo:

Fade In

Loading:

Pulse

완료:

Fade Out

## 조건

로딩이 너무 오래 지속되지 않도록 한다.

페이지 콘텐츠가 로드되면 자동으로 사라진다.

## Mobile

동일한 구조를 사용하되 Typography 크기를 줄인다.
