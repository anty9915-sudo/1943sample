# BRAND 페이지 구현 문서

## 목표

1943CLASSIC 브랜드 철학과 정체성을 보여준다.

## Hero

상단:

```text
BRAND

1943CLASSIC
```

큰 배경 이미지를 사용한다.

## Brand Story

구성:

```text
IMAGE        TEXT
```

Text:

```text
BRAND STORY

젊음에 클래식을 더하다.

1943CLASSIC만의 브랜드 철학과
트렌디한 공간 문화를 소개한다.
```

## Design

이미지는 크게 사용한다.

Text는 충분한 여백을 사용한다.

## Animation

스크롤 시:

* Image Scale
* Text Fade Up
* Heading Reveal

## Brand Philosophy

다음 내용을 카드 형태로 구성한다.

### 01

독보적인 인테리어

### 02

트렌디한 메뉴

### 03

MZ세대 타깃

### 04

지속적인 마케팅

## Hover

카드 Hover:

* Image Zoom
* Gold Overlay
* Text 강조
* translateY

## 요구사항

Brand 페이지는 단순 회사소개가 아니라 1943CLASSIC의 브랜드 경험을 보여주는 페이지로 제작한다.
