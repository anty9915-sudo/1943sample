# INTERIOR 구현 문서

## 목표

1943CLASSIC의 독보적인 인테리어를 시각적으로 강조한다.

## Layout

큰 Main Image와 여러 개의 Sub Image를 사용한다.

```text
        LARGE IMAGE
     
SMALL IMAGE    SMALL IMAGE
```

## Parallax

스크롤 시 이미지마다 이동 속도를 다르게 설정한다.

## Content

```text
INTERIOR

독보적인 인테리어

젊음과 클래식이 공존하는
1943CLASSIC만의 공간
```

## Design

* Full Width
* Large Image
* Dark Overlay
* Gold Typography
* Thin Border

## Animation

* Parallax
* Image Zoom
* Fade Up

## Mobile

Parallax를 약하게 적용하거나 비활성화한다.

이미지는 세로형 Grid로 변경한다.
