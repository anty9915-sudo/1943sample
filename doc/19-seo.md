# SEO 구현 문서

## 기본 Title

```text
1943CLASSIC | 젊음에 클래식을 더하다
```

## Description

```text
1943CLASSIC 브랜드 소개, 메뉴, 매장 안내 및 가맹 창업 정보를 제공합니다.
```

## Meta

각 페이지마다 고유한:

* title
* description

을 설정한다.

## Open Graph

다음 항목을 설정한다.

```text
og:title
og:description
og:image
og:url
```

## Semantic HTML

가능하면 다음 구조를 사용한다.

```html
<header>
<nav>
<main>
<section>
<article>
<footer>
```

## Image

모든 이미지에는 의미에 맞는 alt를 작성한다.
